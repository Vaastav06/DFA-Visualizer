# Project guidance

This repository demonstrates the Dragon Book direct regular-expression-to-DFA construction. Keep application behavior, examples, tests, and documentation centered on the augmented syntax tree, positions, nullable/firstpos/lastpos, followpos, direct DFA states/transitions, and simulation of that DFA.

Run `npm test`, `npm run typecheck`, `npm run lint`, and `npm run build` after source changes. See `docs/COMPILER_PIPELINE.md` for the algorithm and `docs/REGEX_SPECIFICATION.md` for accepted input.
